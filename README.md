# VeloGuard
VeloGuard simplifies reporting stolen bikes and scooters in Switzerland through an interactive map and a report form that sends details to local police.

Features

- Interactive map to select the theft location

- Form to enter bike or scooter details

- Report preparation for local police

- Live website
(https://velo-guard.velo-guard.workers.dev/)

Technologies

- HTML

- CSS

- JavaScript

Purpose

- To make reporting bike and scooter theft easier and more organised.
